argument-hint: <words or path to an .html report>

Run `"${CLAUDE_PLUGIN_ROOT}/scripts/behold" $ARGUMENTS` with Bash. It turns the stage on if needed (do not run presto first), finds a matching report in ~/Downloads (or a path you give), opens it on the stage, frames the first chart and speaks its headline. Report in one line what was opened. macOS only.
